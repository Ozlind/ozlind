# OZLIND

### Your All-in-One AI Companion

OZLIND is a modern, all-in-one AI platform designed to bring powerful AI tools into one unified experience.

## 🚀 Vision

OZLIND aims to provide:

- 🤖 AI Chatbot
- 🎨 AI Image Generator
- 🖼️ AI Photo Editor
- 💻 AI Coding Assistant
- 🔗 GitHub AI Agent
- ▲ Vercel AI Agent
- 📄 PDF & Document AI
- 🌐 Web Research
- 🧠 AI Memory & Conversation History
- 🎙️ Voice AI
- 🔐 Authentication
- 💳 Future AI subscriptions & payments

## ⚡ AI Engine

OZLIND currently uses the **Groq API** as its primary AI provider.

The architecture is designed to support multiple AI providers in the future, including:

- Groq
- OpenAI
- Google Gemini
- Other AI providers

The AI provider layer is separated from the application so providers can be added or replaced without rebuilding the entire platform.

## 🛠️ Technology

- Next.js
- TypeScript
- React
- Tailwind CSS
- Groq API
- Vercel
- GitHub

## 🔒 Security

API keys and sensitive credentials are kept server-side using environment variables.

Never expose API keys in client-side code.
