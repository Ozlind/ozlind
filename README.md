# OZLIND AI

OZLIND is an AI product created by Athul and developed under OZLIND Enterprises.

### Active scope
- AI Chat
- Image analysis
- Web Research
- Local History
- Response Settings

Unimplemented future tools are intentionally absent from the UI.

### Security
Secrets are server-side only. Public UI and assistant identity do not expose internal AI infrastructure. OpenRouter is not included.

### Supabase
Optional server-side event analytics only. Chat history is local; no fake cloud-history UI is presented.
