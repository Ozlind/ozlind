OZLIND — IN-CHAT IMAGE GENERATION V2
======================================

This package changes the product direction:

USER -> types an image request in the normal OZLIND AI chat
     -> OZLIND detects an explicit image-creation request
     -> /api/image-generate
     -> generated image appears directly inside the same chat
     -> Download / Regenerate are available on the image

There is NO separate Image Generator page.

FILES TO REPLACE
----------------
1. chatbot.js
2. api/image-generate.js

FILES THAT ARE NO LONGER NEEDED FOR THIS FLOW
---------------------------------------------
The previously added standalone image-generator files are not used by V2:

- image-generator.js
- image-generator.css
- image-generator-ui.html

Delete those three files from the repository after replacing the two files above.

DO NOT CHANGE
-------------
- index.html boot experience
- style.css
- api/chat.js
- Groq configuration
- Tavily configuration
- .env / .env.example

EXAMPLES
--------
"Create an image of a cinematic Kerala backwater at sunset"
"Generate a realistic portrait of a young man in a studio"
"Make a 16:9 futuristic city wallpaper"

These are handled by the image-generation route and displayed in chat.

NORMAL CHAT
-----------
"Explain quantum computing"
"What is the capital of Japan?"
"Research the latest AI news"

These continue through the existing /api/chat flow.

IMPORTANT
---------
The image provider is intentionally isolated behind /api/image-generate so
the frontend architecture can later switch providers without redesigning
the chat UI.
